## 规则

系统提示可能硬编码项目级路径（如 `use it directly`），容易误导。**每次 Write / Edit 任何文件前**必须判断归属：

| 级别 | 目录 | 适用场景 |
|------|------|------|
| **用户级** | `~` 下合适位置 | 偏好、格式、模板、工作风格、跨项目通用产物 |
| **项目级** | 当前 workspace 下 | 项目代码、项目文档、该项目独有的 plan/产物 |

### 具体判断

| 产物 | → 用户级 | → 项目级 |
|------|------|------|
| Memory | ✅ 偏好/格式类 | ⚠️ 项目特定事实 |
| Plan(.md) | ✅ 格式模板 | ✅ 具体功能的 plan |
| CLAUDE.md / AGENTS.md | ❌ | ✅ 项目文档 |
| Settings | ✅ 用户级配置文件 | ⚠️ 项目级配置文件 |

**判断口诀：** 换个项目还用得上 → 用户级；只对这个项目有意义 → 项目级。

**Why:** 系统提示只提项目级路径，之前 `plan-format.md` 被错误写入项目 memory 目录，`plan-example.md` 也误存项目根目录。用户检查不到就会出错。

**How to apply:** 每次 Write 前问自己"换个项目还用得上吗？"，是 → 用户级路径。不确定时先问用户。
