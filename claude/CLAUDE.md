# 用户全局偏好

## 工作流程
- 每次任务先出 plan，获得明确许可后才能修改文件
- 不允许在未授权的情况下 Edit / Write / Delete 任何文件
- 只读操作（Read, Grep, Glob）不需要许可
- 先分析 root cause，再给方案
- 研究类讨论一律先走 `research` skill：召回 re-history 索引 → 续接历史结论或新建研究
- research skill 中经用户确认的笔记写入视为已授权，可直接落盘

## 沟通风格
- 用中文回复

## Plan 输出格式

### 何时必须走模板（命中任一即触发）
- 用户说「给个 plan / 方案 / 步骤 / 怎么做」
- 你主动提出任何涉及改动的打算，哪怕是 3 行要点
- 提交计划模式（ExitPlanMode）之前
- 调用 TodoWrite 写实现步骤之前
- 任何含「改 / 加 / 删 / 重构 / 迁移 / 优化」的提案

### 硬约束
- 输出计划前必须先 Read `C:\Users\duckknight\.claude\templates\plan-example.md`
- 未读模板前，不得输出任何计划性内容（包括编号列表、要点列表、口头提案）
- 格式严格复用模板：标题 → 耗时 → 目标 → 涉及文件 → Phase(diff) → 每阶段风险 → 最终产出

### 模板骨架（速查；有歧义以模板文件为准）
```text
# 🔧 <一句话标题>
| 耗时 | ~N min |
## 🎯 目标
## 📐 涉及文件        ← 表格：文件 / 角色
## 🟢 Phase N — <名>  ← diff 块 + 风险行（🟢/🟡/🔴）
## 📦 最终产出        ← 表格：文件 / 变动 / 合计
```
